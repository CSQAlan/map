# 家属位置共享演示：默认关闭（P0）

## 范围与实施计划

本轮只关闭不可信的家属共享入口，不构建完整身份认证、不签发家属 token、不改数据库结构。

1. 配置 `ENABLE_DEMO_FAMILY_SHARING` 默认 false；仅 `APP_ENV=dev` 或 `APP_ENV=test` 且显式 true 可用。
2. 手机号家属登录、绑定、监看查询、老人导航快照发布共用门控，在数据库依赖和业务读写之前返回 403。
3. 家属监看收到 403 后停止轮询、清除缓存位置与关联提示，拒绝旧响应；登录/绑定提供明确不可用反馈。
4. 合成数据库与 fetch 夹具验收，禁止连接既有数据库。老人本地规划/导航、管理员、SOS 不加该门控。

## 演示开关变化

默认情况下，旧手机号家属演示不再可用，包括已有浏览器缓存的家属账号。四类接口均返回明确的 403。本地导航仍可使用，收到快照发布 403 后停止本次页面会话的后续共享发布。

只有隔离的本地合成数据演示才可显式设置以下进程环境变量，并重启后端；不需要更改真实 `.env`：

```powershell
$env:APP_ENV='dev'
$env:ENABLE_DEMO_FAMILY_SHARING='true'
```

`APP_ENV` 必须显式设置，不能仅依赖默认开发环境。`test` 同样允许；`prod`、`production`、未知值、空值及其他环境名称即使开关为 true 也拒绝。禁用时设置 false 后重启。开关由后端配置缓存控制，不是运行时远程撤销系统。拒绝后前端停用本次会话的轮询/发布；重新启用后刷新页面、重新登录。

## 验收与风险边界

使用 `backend/tests/test_demo_family_sharing.py` 验证默认关闭、环境白名单、数据库依赖未进入，以及显式启用后的合成登录→关联码校验→绑定→快照→监看。导航快照测试必须显式开启 test 演示。

前端 `family-monitor.test.js`、`auth-session.test.js` 验证 403 清理及迟到响应竞态；`navigation-journey.test.js`、`route-planner.test.js` 保留本地导航回归。

手机号不是可信身份，关联码也不替代身份认证或正式授权。显式开启的旧演示仍接受调用者提供的用户 ID，没有解决冒用、越权、共享同意及撤销问题，严禁用于真实人员位置。不得把该开关作为生产认证方案。历史数据库快照不会被删除；本轮不进行数据迁移或清理。
