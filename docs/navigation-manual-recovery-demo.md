# 主动核对我走到哪

用户按文字走路时，也可能忘记自己正在看哪一段。以前只有定位异常才出现核对卡，未开定位、等待定位或定位良好时缺少主动核对入口。

实现沿用 `NavigationPage.vue` 的 `recoveryIssue`、`recoverNavigation` 和已有普通登记路线校验：新增本页展开状态，主动与自动提示共用一张卡；自动异常仍独立显示。先以组件测试和本地 fixture 浏览器检查验证失败，再实现并执行完整测试、构建及旧 recovery 浏览器回归。

## 45 秒演示

1. **0–10 秒**：开始普通登记路线，保持定位关闭。点击明显的「我不确定走到哪」，卡片显示手动第几段和本段名称，并说明不能确认实际站位。
2. **10–20 秒**：点击「关闭核对」，或再次打开后按 Escape，焦点回到入口。开关卡片不移动地图，不启用定位、不播报、不推进段数、不通知家属。
3. **20–30 秒**：打开卡片，点「查看本段登记地图」，只手动居中已核对的登记段；再点「按本段文字继续」，段数保持不变。两种操作均不自动开启定位或恢复跟随。
4. **30–45 秒**：模拟定位异常，主动打开后仍只有一张卡；关闭主动状态，原异常卡仍在。切段、换路线、身份范围变化、休息、核对障碍、绕行、结束或离开页面会清理主动展开状态。

主动入口只在有效普通导航正在走且手动段数和登记资料已核对时提供；没有有效登记段、待确认障碍、休息、绕行或结束时隐藏。卡片仅帮助核对登记信息，不判断实际位置、转弯或到达。

node scripts/check-navigation-recovery.mjs --no-artifacts
