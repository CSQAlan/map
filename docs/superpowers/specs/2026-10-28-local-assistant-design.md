# 本地 Ollama 助老助手设计

日期：2026-10-28

## 方案与授权
用户要求本地Ollama助手并自主审批。本机已安装qwen3.5:4b，不下载新模型。比较浏览器直连、后端代理、自动工具执行，采用后端代理，提供使用问答和路线解释。完成探索、方案展示、自主审批和书面规格自查。

## 接口和推理
GET /api/assistant/status 检查服务及配置模型；POST /api/assistant/chat 接受有限长度user/assistant历史及可选结构化路线摘要。客户端不能传system、工具、模型名或地址。配置OLLAMA_BASE_URL（http://127.0.0.1:11434）、OLLAMA_MODEL（qwen3.5:4b）、OLLAMA_TIMEOUT_SECONDS（90）。httpx异步请求/api/chat，stream=false、think=false，限制输出token和并发2。离线、模型缺失、超时、坏响应返回可操作中文错误；状态不泄露内网地址。

上下文仅含画像、起终点、距离和摘要；不含身份、电话、坐标、健康问卷，可通过界面开关控制。system将上下文作为数据，不声称实时安全、不伪造规划或已执行操作。纯文本显示回答，不执行HTML。

## 页面
/elder/assistant：欢迎说明、快捷问题、对话、加载、取消、清空、输入框和连接重试。最多1000字，最多12条历史，裁剪保留成对历史，服务端校验交替角色。请求期间防重复提交，失败恢复输入，离页取消，不持久化聊天。

## 验证
后端mock验证成功、校验、system注入、离线、模型缺失、超时、忙和坏响应；前端验证消息、失败、取消、清空；至少一次真实本地中文生成。手机和桌面视觉检查，记录真实结果。
