# 手机优先界面升级设计

日期：2026-10-28

## 方案与授权
用户要求美化前端、主要面向手机，并授权自行审批。比较轻量换肤、手机任务流改版、复杂地图首页三种方式，选择手机任务流改版。完成项目探索、视觉预览选择、需求推导、方案比较与展示，自主审批规格，转入 writing-plans。

## 视觉和结构
深青绿、雾白、大字、48px触控和线性SVG图标。手机底栏五项：首页、路线、助手、资料、我的；桌面侧栏。首页展示社区步道示意插画（不是实际地图）与明确的地点查询主操作。快捷目的地来自实际POI选项，画像偏好可展开。统一登录、路线卡、表单和公共表面，保留业务事件和权限流程。长内容自然滚动，预留底部安全区，保持键盘焦点与减少动态效果。

## 验收及边界
检查320、390、768、1440宽度溢出、底栏遮挡、入口可达；前端测试和构建通过并截图。沿用后端契约和踩点/导航数据隔离。原有router未提交修正经审查后一起保存，原始照片、map.zip、dist-review不提交。规格已经自查占位、矛盾、范围与歧义。
