# 导航途中与地图体验设计

日期：2026-10-28

采用逐段指引+用户主动定位；不在路网方向信息不足时伪造转弯或自动进段。保留路线算法、正式路网/踩点隔离和原有SOS。

当前段独立突出显示，提供上一段、我已走完这一段、休息/继续、重播、语音开关、结束确认及返回路线。剩余距离依据手动完成段长估算，标记为估算；结束导航不冒充GPS确认到达。进段同步地图选段、求助与家属当前段状态。

用户点击后才请求连续定位；结束/离页停止watch。明确权限、精度差、数据过期及定位未启用状态。GPS WGS84转为与地图一致的GCJ02，与请求GCJ02的地图路段比较；不使用路线详情中未明确转换的几何。偏离提醒需连续3次新鲜且精度<=30米样本、距离大于max(40米,2倍精度)，不自动重规划、不自动进段。无路网几何不判断偏离。

地图使用元素ref替代固定ID；加载中离页不再创建地图。初次显示拟合路线，选段只改样式，不反复重置缩放。提供完整路线、当前段和我的位置控制，定位与精度圈独立更新。降级路网保留点击、键盘及位置可见提示；不把降级简图称作完整离线底图。

验证覆盖段落推进/风险播报/剩余距离、坐标转换、精度/过期/连续偏离、GPS清理、地图异步卸载；手机布局、低视口和端到端分段操作。真实GPS/真实地图Key/物理手机效果如实列为未验证。设计依据既有用户自主授权采用，规格已检查范围与歧义。
