# 语音与助手体验打磨

日期：2026-11-09。用户已选择并同意本轮方案 1；沿用暂停验证的要求。

## 范围

- 共享录音组件显示已录秒数、剩余秒数及进度条。计时从录音真正开始时启动，离开录音状态和卸载时清理。30秒自动识别继续由既有录音服务负责。
- 等待麦克风授权、识别中的状态分别给出说明，保留取消入口，不展示虚假的识别百分比。
- 助手收到识别文字后继续追加到草稿，保留1000字限制与超长提示，聚焦输入框供用户核对，仍需主动发送。
- 新对话前取消正在等待的助手回答，将恢复的文字也纳入草稿保护。有草稿时使用原生模态对话框，让用户选择保留文字后新建、返回编辑或放弃文字后新建。录音或转写期间禁用新对话，避免晚到文字进入新对话。
